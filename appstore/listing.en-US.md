# Bolt Photo Viewer: Mac App Store listing (English)

## Subtitle (max 30 characters)

Browse photo folders fast

## Promotional text (max 170 characters)

Probably the fastest photo viewer. No delay when opening or switching photos! Quick actions (rotate, rate, batch operations), and every one can be undone.

## Description (max 4000 characters)

Bolt shows photos from ordinary folders on your Mac. Double-click in Finder and the photo is already on screen, and the arrow keys flip through the whole folder. The next shot appears instantly after the key press, and it is sharp right away, with no blurry preview. All popular formats open: HEIC from an iPhone, JPEG, PNG, RAW, WebP, AVIF and animated GIF.

You can sort through your shots without taking your hands off the keyboard:

• ⌫ sends the photo to the Trash and shows the next one, no questions asked
• 1–9 move the photo to assigned folders, ⌥1–9 copy it there
• P, X and U set a flag, ⌃1–5 a rating, ⌃6–9 a color label
• [ and ] rotate, C crops
• E exports with a preset, for example JPEG 85%, 2560 pixels, no location data
• . repeats the last action for the next photo

Any file action can be undone with ⌘Z. Bolt never deletes a file without going through the Trash and never overwrites an existing one. Flags, ratings and labels are stored in Finder tags, so you can see them in Finder too, and the file itself does not change. Rotating changes only the orientation tag, the pixels stay the same. RAW+JPEG pairs and both halves of a Live Photo move together.

For viewing:
• grid and thumbnail strip
• EXIF panel: camera, lens, shutter speed, location
• compare up to four photos side by side with a shared zoom
• 100% and fit-to-width zoom; when you flip through photos, the zoom and position are kept, which makes it easy to check a series for sharpness
• HDR on displays that support it
• Live Photo, video and animation
• slideshow and full screen mode

For batch work: converting and resizing, renaming by a template with the capture date and a counter, removing location data and serial numbers without recompressing.

The keys work in any keyboard layout. ? shows the list of them, ⌘K opens all commands. Any key can be reassigned.

Bolt works with folders as they are. It imports nothing and keeps no library. When you open a photo from a new folder, Bolt asks for access to it once. If you allow your home folder, it will not ask again.

No accounts, no subscription, no analytics. Bolt never connects to the internet.

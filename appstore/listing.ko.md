# Bolt Photo Viewer: Mac App Store listing (한국어)

## Subtitle (max 30 characters)

사진 폴더를 빠르게 넘겨 보기

## Promotional text (max 170 characters)

아마도 가장 빠른 사진 뷰어. 사진을 열 때도, 넘길 때도 지연이 전혀 없습니다! 빠른 동작(회전, 별점, 일괄 작업)은 무엇이든 되돌릴 수 있습니다.

## Description (max 4000 characters)

Bolt는 Mac의 일반 폴더에 있는 사진을 보여 줍니다. Finder에서 더블 클릭하면 사진이 바로 화면에 나타나고, 화살표 키로 폴더 전체를 넘겨 볼 수 있습니다. 키를 누르면 다음 사진이 즉시 나타나며, 흐릿한 미리보기 없이 처음부터 선명합니다. iPhone의 HEIC, JPEG, PNG, RAW, WebP, AVIF, 움직이는 GIF까지 주요 형식을 모두 열 수 있습니다.

키보드에서 손을 떼지 않고 사진을 정리할 수 있습니다.

• ⌫ 사진을 휴지통으로 보내고 다음 사진을 보여 줍니다. 묻지 않습니다
• 1–9 사진을 지정한 폴더로 이동하고, ⌥와 함께 누르면 복사합니다
• P, X, U 깃발을 지정하고, ⌃1–5 별점, ⌃6–9 색상 레이블을 지정합니다
• [ 와 ] 회전하고, C 자릅니다
• E 프리셋으로 내보냅니다. 예를 들어 JPEG 85%, 2560픽셀, 위치 정보 없음입니다
• . 마지막 동작을 다음 사진에 반복합니다

파일에 대한 모든 동작은 ⌘Z로 되돌릴 수 있습니다. Bolt는 휴지통을 거치지 않고 파일을 삭제하지 않으며, 기존 파일을 덮어쓰지도 않습니다. 깃발, 별점, 레이블은 Finder 태그에 저장되어 Finder에서도 보이고, 파일 자체는 바뀌지 않습니다. 회전할 때는 방향 태그만 바뀌고 픽셀은 그대로입니다. RAW+JPEG와 Live Photo의 두 파일은 함께 이동합니다.

보기 기능:
• 격자와 섬네일 스트립
• EXIF 패널: 카메라, 렌즈, 셔터 속도, 촬영 장소
• 최대 네 장의 사진을 나란히 놓고 같은 배율로 비교
• 100% 배율과 폭에 맞춤. 넘겨 볼 때 배율과 위치가 유지되어 연속 촬영한 사진의 선명도를 확인하기 좋습니다
• HDR을 지원하는 디스플레이에서 HDR 표시
• Live Photo, 비디오, 애니메이션
• 슬라이드쇼와 전체 화면 모드

일괄 작업: 변환과 축소, 촬영 날짜와 카운터가 들어간 템플릿으로 이름 변경, 재압축 없이 위치 정보와 일련번호 삭제.

키는 어떤 자판 배열에서도 작동합니다. ? 를 누르면 키 목록이 나오고, ⌘K는 모든 명령을 엽니다. 어떤 키든 다시 지정할 수 있습니다.

Bolt는 폴더를 있는 그대로 다룹니다. 아무것도 가져오지 않고 보관함도 관리하지 않습니다. 새 폴더의 사진을 열면 Bolt가 해당 폴더에 대한 접근 권한을 한 번 요청합니다. 홈 폴더를 허용하면 더 이상 묻지 않습니다.

계정도, 구독도, 분석도 없습니다. Bolt는 네트워크에 접속하지 않습니다.
